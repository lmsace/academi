<h3>Academi Theme - Installation Steps</h3>

<ul>


<li>Unzip the downloaded theme package. You will get a folder named 'academi'</li>

<li>Copy the 'academi' folder into the 'theme' directory of your Moodle system.</li>

<li>Log in as Site Administrator.</li>

<li>Go to <strong>Site administration → Notifications</strong>. On the 'Plugins check' page, you will see the Academi theme listed.</li>

<li>Click the "Upgrade Moodle database now" button displayed at the bottom of the page.</li>

<li>You will receive a success message once the theme is installed successfully.</li>

<li>Click the "Continue" button on the success page to access the Academi theme settings.</li>

<li>You can modify the theme settings at any time later :-).</li>

</ul>


<h3>Steps to Set Academi as the Default Theme</h3>

<ul>

<li>Login as Site Administrator.</li>

<li>Go to <strong>Site administration → Appearance → Themes</strong>.</li>

<li>All available themes for the default device will be listed.</li>

<li>Click the "Select theme" button under the Academi theme.</li>

<li>Cheers !!!, The Academi theme is now set as your default theme.</li>
